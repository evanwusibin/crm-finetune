> **日期**：2026-06-25

## 核心技巧：用轻量模型部署，节省下载时间

### 问题

在 AutoDL 上部署大模型（如 Qwen3-8B）时：
- 模型下载需要很长时间（16GB+）
- 下载期间 GPU 一直在计费
- 浪费钱

### 解决方案

```
Step 1：在 AutoDL 上创建实例时，选择"轻量模型"
Step 2：先用轻量模型跑通流程
Step 3：需要大模型时，从本地克隆到 GPU
Step 4：这样下载时间不计费（或计费很少）
```

### 具体操作

```bash
# 1. 在 AutoDL 上创建实例
#    选择 GPU：RTX 4090 24GB 或 A100 40GB
#    选择镜像：PyTorch 2.x + CUDA 12.x

# 2. 本地打包模型
cd D:\heimaAI\PytorchSDXX\10_微调\crm-finetune\model
tar -czf Qwen3-4B.tar.gz Qwen3-4B/

# 3. 上传到 AutoDL（用 SCP 或文件管理）
scp Qwen3-4B.tar.gz root@autodl.com:/root/

# 4. 在 AutoDL 上解压
tar -xzf Qwen3-4B.tar.gz

# 5. 开始训练/部署
python train_qlora.py
```

### 省钱对比

| 方案 | 模型下载时间 | GPU 计费时间 | 总成本 |
|---|---|---|---|
| 直接下载 | 30-60 分钟 | 30-60 分钟 | 贵 |
| 本地克隆 | 5-10 分钟 | 5-10 分钟 | 便宜 |

**省下的钱可以多跑几次实验。**

## AutoDL 使用建议

### 选择 GPU

| 任务 | 推荐 GPU | 价格（约） |
|---|---|---|
| 学习/测试 | RTX 3090 24GB | 1-2 元/小时 |
| 小模型训练 | RTX 4090 24GB | 2-3 元/小时 |
| 大模型训练 | A100 40GB | 5-8 元/小时 |
| 大模型训练 | A100 80GB | 10-15 元/小时 |

### 省钱技巧

| 技巧 | 说明 |
|---|---|
| 用完关机 | 不用时及时关机，避免空跑 |
| 选择竞价实例 | 价格便宜 50-70%，但可能被抢占 |
| 本地打包上传 | 避免在 GPU 上下载大文件 |
| 用小模型测试 | 先用 0.6B 跑通，再用 4B/8B |
| 批量训练 | 把多次实验合并到一次 GPU 使用 |

### 文件传输方法

```bash
# 方法 1：SCP（命令行）
scp -r ./model root@autodl.com:/root/model

# 方法 2：AutoDL 文件管理（网页上传）
# 登录 AutoDL → 文件管理 → 上传

# 方法 3：网盘中转
# 上传到网盘 → 在 AutoDL 上下载
```

## 本地 vs AutoDL 对比

| 维度 | 本地（RTX 5070 Ti） | AutoDL（RTX 4090） |
|---|---|---|
| 显存 | 12GB | 24GB |
| 能跑的模型 | 4B BF16 | 8B BF16 |
| 成本 | 电费 | 2-3 元/小时 |
| 速度 | 较慢 | 较快 |
| 适用场景 | 学习、小实验 | 生产训练、大模型 |

## 总结

| 阶段 | 用什么 | 原因 |
|---|---|---|
| 学习阶段 | 本地 RTX 5070 Ti | 免费，够用 |
| 原型验证 | 本地或 AutoDL | 看模型大小 |
| 生产训练 | AutoDL | 显存大、速度快 |
| 生产部署 | 服务器 | 24/7 运行 |
