# 服务启动与停止指南

> 适用于：CRM 微调模型 + RAG 项目联合部署

---

## 一、启动服务

### 1. 启动 Docker 容器（MongoDB + Milvus）

```bash
# 启动 MongoDB
docker run -d --name mongo -p 27017:27017 mongo:7

# 启动 Milvus（etcd + minio + standalone）
cd D:\heimaAI\PytorchSDXX\08_掌柜智库\实战\实战\auto-carcrm
docker compose -f docker-compose.milvus.yml up -d
```

### 2. 启动模型 API 服务

```bash
cd D:\heimaAI\PytorchSDXX\10_微调\crm-finetune
# 域内专用（Qwen3-4B-QLoRA-BYd-v2）
.venv\python.exe serve_openai.py
# 或 Hybrid 融合（域内 + Sensenova glm-5.2 + 联网兜底）
.venv\python.exe serve_hybrid.py
```

等待看到：`模型加载完成！` 和 `启动 API 服务：http://0.0.0.0:8100`（域内）/ `http://0.0.0.0:8101`（Hybrid）

> Hybrid 需 `.env` 配置 `FUSION_API=https://token.sensenova.cn/v1/chat/completions` + `FUSION_API_KEY=sk-...`，详见 `docs/hybrid_design.md`

### 3. 启动 RAG 项目

```bash
cd D:\heimaAI\PytorchSDXX\08_掌柜智库\实战\实战\auto-carcrm
python -m app.main
```

等待看到：`Uvicorn running on http://0.0.0.0:8000`

### 4. 注册测试账号（首次使用）

```bash
curl -X POST http://localhost:8000/auth/register -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"123456\",\"email\":\"admin@test.com\"}"
```

## 二、停止服务

### 1. 停止 Python 服务

```bash
# 在对应终端按 Ctrl+C 即可停止
# 或者强制杀进程
taskkill /F /IM python.exe
```

### 2. 停止 Docker 容器

```bash
# 停止所有相关容器
docker stop mongo milvus-standalone milvus-etcd milvus-minio
```

### 3. 删除容器（可选，释放资源）

```bash
# 删除容器（数据保留在 Docker volume 中）
docker rm mongo milvus-standalone milvus-etcd milvus-minio
```

### 4. 删除数据卷（可选，彻底清理）

```bash
# 删除 Milvus 和 MinIO 数据
docker volume rm auto-carcrm_milvus-data auto-carcrm_minio-data auto-carcrm_etcd-data

# 删除 MongoDB 数据
docker volume rm mongo-data
```

## 四、常见问题

### Q1: MongoDB 连接失败

```
错误：由于目标计算机积极拒绝，无法连接。 (127.0.0.1:27017)
```

**解决**：启动 MongoDB 容器

```bash
docker run -d --name mongo -p 27017:27017 mongo:7
```

### Q2: Milvus 连接失败

```
错误：pymilvus.exceptions.MilvusException: <MilvusException: (code=2, message=Fail connecting to Milvus)>
```

**解决**：启动 Milvus 容器

```bash
cd D:\heimaAI\PytorchSDXX\08_掌柜智库\实战\实战\auto-carcrm
docker compose -f docker-compose.milvus.yml up -d
```

### Q3: 模型 API 连接失败

```
错误：Connection refused (localhost:8100)
```

**解决**：启动模型 API 服务

```bash
cd D:\heimaAI\PytorchSDXX\10_微调\crm-finetune
.venv\python.exe serve_openai.py
```

### Q4: Docker Desktop 未启动

```
错误：failed to connect to the docker API
```

**解决**：启动 Docker Desktop

```bash
Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"
```

taskkill /F /IM python.exe
docker stop mongo milvus-standalone milvus-etcd milvus-minio

# 2. 启动 Docker
docker start mongo milvus-standalone milvus-etcd milvus-minio

# 3. 启动模型 API（终端 1）
cd D:\heimaAI\PytorchSDXX\10_微调\crm-finetune

# 4. 启动 RAG（终端 2）
cd D:\heimaAI\PytorchSDXX\08_掌柜智库\实战\实战\auto-carcrm
