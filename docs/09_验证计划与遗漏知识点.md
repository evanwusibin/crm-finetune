## 三、面试验证清单

### 3.1 基础问题（必答）

| 问题 | 参考答案 |
|---|---|
| 什么是 LoRA？ | 冻结原始权重，只训练两个小矩阵，用少量参数实现微调 |
| LoRA 的 r 参数怎么选？ | 通常 8-64，r 越大效果越好但显存越大，从 16 开始调 |
| SFT 和 RLHF 的区别？ | SFT 教"说什么"，RLHF 教"怎么说人话" |
| 微调和 RAG 怎么选？ | 高频更新用 RAG，领域知识用微调 |
| 什么是量化？ | 把模型权重从高精度（FP16）压缩到低精度（INT8/INT4） |

### 3.2 进阶问题（加分）

| 问题 | 参考答案 |
|---|---|
| LoRA 和全参微调效果差多少？ | 通常差 1-3%，但显存省 90%+ |
| 为什么 QLoRA 学习率比 LoRA 大 10 倍？ | 4bit 量化后参数变化更大，需要更大步幅 |
| 怎么判断过拟合？ | eval_loss 上升但 train_loss 下降 |
| 什么是梯度累积？ | 用时间换显存，小 batch 模拟大 batch |
| PagedAttention 是什么？ | 推理时按需分配 KV Cache 显存，提高并发 |

### 3.3 项目经验问题

| 问题 | 你的回答 |
|---|---|
| 你微调了什么模型？ | Qwen3-4B，用 LoRA 微调 CRM 汽车售后数据 |
| 数据量多少？ | 52 条训练数据（FAQ + 维修案例 + 故障码） |
| 训练多久？ | 500 步，约 1.5 小时 |
| 效果怎么评估？ | loss 下降、accuracy 上升、人工评估回答质量 |
| 遇到什么问题？ | QLoRA 不支持新 GPU、模型太大放不进显存 |
